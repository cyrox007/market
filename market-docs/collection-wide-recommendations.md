# Прототип: массовые сопутствующие товары по мебельной серии

## Как включить

1. В админке откройте **Товары → Подборки товаров**.
2. Создайте ручную подборку **Бруно**: автоматический отбор выключен, правило отбора пустое, подборка активна.
3. В разделе «Товары в подборке» укажите **родительские карточки**: шкаф, антресоль, комод и другие товары серии. Цветовые торговые предложения остаются внутри своих карточек.
4. Включите переключатель **«Рекомендовать все товары серии друг у друга»**. Он также доступен в таблице подборок как «Рекомендации серии».
5. В существующем блоке «Похожие товары» карточки этой серии теперь рекомендуют остальные карточки, без назначения сопутствующих поштучно. Новые члены серии появятся в рекомендациях автоматически после добавления в подборку.

## Массовое наполнение серии (по аналогии с прежним менеджером товаров)

Если серия «Бруно» уже создана, **не нужно добавлять каждый шкаф и антресоль по одной карточке**:

1. Откройте **Товары → Товары**, отфильтруйте производителя (фабрику), затем найдите «Бруно» в поиске по названиям.
2. Отметьте нужные **родительские карточки** (без отдельных цветовых торговых предложений).
3. В массовых действиях выберите **«Добавить товары в серию»**, укажите ручную подборку «Бруно» и действие **«Добавить»**.
4. Включите **«Взаимные рекомендации серии»** в форме (по умолчанию включено при добавлении). Теперь у антресоли будут показываться шкафы, у шкафов — антресоли и другие товары именно этой подборки.
5. Чтобы убрать выбранные позиции, повторите операцию с действием **«Убрать из серии»**. Другие товары и их ручные рекомендации не удаляются.

Название «Бруно» и фабрика — **только критерии поиска для оператора**. Принадлежность к серии фиксируется явно в существующей таблице ручной подборки. Одного совпадения подстроки в названии товара недостаточно для автоприсвоения. Новые товары, которые **явно добавлены** в подборку, автоматически станут видны другим участникам серии.

Для точечных исключений или независимых ручных рекомендаций существует в том же менеджере ещё одна массовая операция: **«Массово назначить сопутствующие»** (добавить/удалить/заменить, целевые карточки выбираются вручную). Она записывает симметричные связи между карточками и **не назначает товары в коллекцию**. Одни и те же группы лучше не дублировать через оба режима: приоритет ручных рекомендаций зависит от режима конкретного продукта.

## Контракт API и приоритеты

- Используются действующие GET /api/v1/products/{id}/related и GET /api/v1/products/{slug}, поле related.data. Форма ответа не меняется.
- Правило включается только для активной ручной подборки без scope_type, когда recommend_collection_members=true. Оно не затрагивает автоматически сформированные системные подборки «Хиты», «Новинки», «Акции».
- Исключаются текущий товар, неактивные карточки, отдельные цветовые варианты и товары, уже показанные в редакторской подборке набора. Цветовые варианты доступны через родительскую карточку. Пересечения нескольких серий дедуплицируются.
- Порядок: меньший priority подборки раньше; в подборке — sort_order, затем ID товара. Не более 24 рекомендуемых родительских карточек в одном API-ответе.
- При related_products_mode=off рекомендации отключены, при manual — только явные ручные связи (до 4). При старом null ручные связи имеют приоритет, затем серия, затем категории. При automatic сначала серия, иначе прежняя категория/общий fallback.
- Изменения списка и переключателя через Filament сбрасывают продуктовый API-кэш через ProductCollectionCacheService.
- Переключатель выключен по умолчанию. Миграция не меняет поведение существующих подборок.

## Не является продаваемым комплектом

Это механизм показа остальных товаров серии. Он не добавляет товары в корзину, не создаёт связи в product_related_products, не меняет состав sellable_bundle_components, остатки, заказы или обмен с 1С.

## Границы прототипа

Привязка к серии делается через редактор ручной подборки **или новую массовую операцию в менеджере товаров**; массовое подключение действует сразу для всех её участников. На фронтенде используется существующая карусель «Похожие товары» и её заголовок не меняется. При необходимости отдельный блок «Другие товары серии» можно добавить позже с явным источником рекомендаций в API.
