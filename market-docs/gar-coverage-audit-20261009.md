# Проверка покрытия ГАР и координат, 09.10.2026

Проверены живой API `https://api.svetofor-mebel.ru/api/v2/address/directory/status`, SQL-агрегаты в production (только чтение), локальная очередь импорта и исходник OSM. Числа ГАР меняются по мере работы очереди.

Во время проверки импорт прошёл регионы 01–14 и ранее загруженный 48; обрабатывается следующий пакет. Очередь содержит все 96 региональных пакетов исходного архива ГАР от 06.10.2026. На этом этапе около 191 тысяч адресных объектов и 4,01 млн зданий; это НЕ полная Россия. `garReady=false` — переключать справочник полностью на ГАР пока рано.

## Координаты: отдельный пробел

В production 52 726 строк `locality_coordinates`, все источник OSM и метод `unique_region_name`. Есть записи в 74 кодах регионов. Это центры населённых пунктов (`settlement_centre`), не координаты зданий.

В локальном `storage/geodata/osm/places.sqlite` 151 669 исходных OSM-точек. Эти числа нельзя напрямую делить для получения процента покрытия: в источниках разная полнота, неоднозначные имена и состав объектов. Несопоставленные записи не загружаются под случайными ID.

Следовательно, полная загрузка ГАР сама по себе не обеспечивает координатами каждый населённый пункт и тем более каждый дом. Нужен второй проход сопоставления: явные идентификаторы, территориальная принадлежность по границам/иерархии, обработка одноимённых поселений, отчёт по несопоставленным объектам. Не подменять это поиском ближайшей одноимённой точки без проверки региона.

## Условия завершения по всей стране

1. Все 96 ожидаемых scopes завершены на одном снимке, нет failed/processing. Не считать число уже существующих scopes полным перечнем страны.
2. Сверены counts и связи по каждому пакету, выборочные адресные цепочки по регионам.
3. Отдельно опубликовано покрытие координат по регионам, явные пропуски и точность; отсутствие точки возвращается как null, не 0,0.
4. Адреса складов используют фактическую точку площадки/отгрузки. Доставка по расстоянию не основывается на выдуманной координате здания.

На сервере при проверке около 21 ГБ свободно. Очередь загружает по одному пакету, проверяет SHA256, сохраняет запас места и удаляет только успешно импортированный временный ZIP. Локальный runner требует включённого компьютера, доступного D: и SSH; это не серверная автономная задача.
