# Адрес склада и расстояние

Админка: Доставка → Склады → создание/редактирование.

1. Найдите населённый пункт (минимум две буквы). В результатах есть регион для различения одноимённых городов.
2. Выберите улицу. Для домов без улицы оставьте поле пустым.
3. Найдите конкретный дом/корпус/строение. Полный адрес проверяется сервером при сохранении.
4. Укажите широту и долготу фактической точки склада. Это не центр населённого пункта. Обе координаты обязательны вместе.

В списке складов видны адрес и наличие координат. При замене населённого пункта, улицы или здания старые координаты очищаются. При недоступности API существующий подтверждённый адрес можно сохранить без повторного запроса.

## Идентификаторы

`address_external_id` — реальный ID записи справочника; `gar_guid` — GUID здания, если источник ГАР; `kladr_code` — код совместимости. Отсутствующий GUID не выдумывается из КЛАДР.

Пока API использует КЛАДР во время импорта ГАР, строки с несколькими домами разворачиваются в отдельные варианты. Составной ключ `ID::номер` используется только в форме; в БД остаётся исходный ID и `address_snapshot.selectedBuildingNumber`. Диапазоны номеров не превращаются в выдуманные здания. После завершения импорта оператор может заменить старую запись конкретным зданием ГАР.

`address_snapshot` хранит проверенную иерархию. Координаты оператора отмечаются `coordinate_source=operator`, `coordinate_precision=warehouse_point`. Координаты центра города из справочника автоматически не подставляются вместо координат склада.

## Расстояние

`WarehouseDistance::kilometres($warehouse, $latitude, $longitude)` возвращает расстояние по прямой в километрах или `null`, если точка склада неизвестна. Ноль означает совпадение точек, а не отсутствие данных.

`FulfillmentSourceResolver::resolve($product, $destination, ['latitude' => ..., 'longitude' => ...])` сначала фильтрует активные источники по наличию товара и зоне доставки, затем сортирует доступные источники по расстоянию. Склады без координат идут после измеренных. Без третьего аргумента прежняя сортировка по срокам и цене сохраняется. В выдаче есть `distance_km`, `distance_available`, `distance_type=straight_line`.

Это подготовка backend-контракта: существующие вызывающие участки должны передать выбранную геопозицию/координаты адреса. Расстояние по прямой не является автомобильным маршрутом и само по себе не изменяет тариф или обещанный срок.

## Выкладка

Перед применением `2026_10_09_100000_add_warehouse_address_snapshot` сделайте резервную копию. Миграция добавляет идентификаторы и снимок адреса, расширяет текст полного адреса, существующие склады не удаляет. Код формы, resolver, модель и миграцию выкладывать совместно через develop после ревью PR.
