# Визуальный редактор описания товара

Ветка: `feature/product-description-editor`. На сервер пока не развёрнуто.

- Используется штатный RichEditor Filament, без установки новых зависимостей.
- Панель: жирный/курсив/подчёркивание, заголовки, списки, цитата, ссылка, отмена/повтор.
- Формат хранения остаётся HTML; миграции БД не требуются.
- Старый plain text преобразуется в абзац с явными переносами до загрузки в документ редактора.
- HTML очищается серверным sanitizer Filament/Laravel при сохранении.
- Загрузка вложений из редактора не предлагается; фотографии и документы остаются отдельными блоками.
- У кнопок панели есть русские подсказки и доступные названия.

## Проверки

- 7 PHP-тестов / 32 проверки: переносы plain text, безопасный HTML, открытие и сохранение
  формы, старые таблицы/картинки/списки, отключение новых загрузок вложений.
- В браузере на локальном черновике 3085 проверены инициализация TipTap без ошибок
  `getEditor` / `length`, жирный текст, маркированный список, ссылка, Enter / Shift+Enter,
  вставка Word-подобного HTML и сохранение с повторным открытием.
- Сохранённый HTML дополнительно проверен в локальной БД: форматирование осталось,
  лишние стили Word удалены. Это не проверка всех возможных документов Word.

Изменения только в админке и её обработке описания. Публичный фронт не меняется и не
пересобирается этой задачей. Стили отображения HTML на витрине остаются ответственностью фронта.
Массовое преобразование описаний не выполняется; в боевой БД ничего не менялось.
Старая нестандартная HTML-разметка может нормализоваться редактором при сохранении;
произвольные inline-стили намеренно не сохраняются. Стандартные таблицы, картинки,
списки, заголовки и ссылки покрыты проверками.
