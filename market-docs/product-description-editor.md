# Визуальный редактор описания — начальная реализация

Ветка: `feature/product-description-editor`. На сервер пока не развёрнуто.

- Используется штатный RichEditor Filament, без установки новых зависимостей.
- Панель: жирный/курсив/подчёркивание, заголовки, списки, цитата, ссылка, отмена/повтор.
- Формат хранения остаётся HTML; миграции БД не требуются.
- Старый plain text преобразуется в абзац с явными переносами до загрузки в документ редактора.
- HTML очищается серверным sanitizer Filament/Laravel при сохранении.
- Загрузка вложений из редактора не предлагается; фотографии и документы остаются отдельными блоками.

Перед выпуском обязательно проверить в браузере инициализацию TipTap: ранее на Filament 4.3
редактор заменяли Textarea из-за клиентской ошибки `getEditor` / `length`.
PHP-тест не доказывает исправность клиентской инициализации.
Также нужны визуальная сверка форматирования с карточкой сайта, вставка из Word и
проверка старых сложных описаний (таблицы, картинки, нестандартная разметка).
Массовое преобразование существующих описаний не выполняется.
