# Услуги и магазины: единый источник настроек

- Подъём, разгрузка, сборка и дополнительные услуги рассчитываются только по `service_tariffs` выбранного профиля склада.
- `null` не означает переход к старой локации: профиль требует настройки. Пустой массив означает отсутствие настроенных услуг.
- Старые маршруты расчёта доставки и админские разделы локаций, перевозчиков и региональных методов отключены в составе warehouse-only перехода.
- Справочники услуг остаются: они описывают услугу, но не задают глобальную цену.
- Магазин использует общую физическую площадку. Адрес и координаты не вводятся независимо. Старый магазин при следующем сохранении требует назначения площадки; записи автоматически не удаляются.
- При сохранении через форму магазина `shipping_location_id` очищается. Старый регион не является источником правил доставки.
- Текстовое время работы служит для показа. Структурированное расписание и часовой пояс используются для самовывоза.
- Встраиваемая карта — только оформление, не источник координат расчёта.
- Перед развёртыванием нужно настроить профили складов и площадки: старые тарифы не должны молча становиться нулевыми.

Фронтенд этим изменением не обновляется. Его вызовы удалённых API требуют перехода на складские API; совместимость со старыми расчётами намеренно не сохраняется.
