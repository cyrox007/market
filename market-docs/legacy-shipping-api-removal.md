# Удаление старой доставки отложено

Первоначальная версия PR #96 удаляла старые редакторы локаций и региональных методов доставки, API regions/localities/shipping и адресные мосты.

После проверки 23.10.2026 удаление отменено: действующий фронт ещё вызывает эти API в выборе города, SSR, оформлении заказа, адресах кабинета и поиске локаций. Удаление приводило бы к 404.

В совместимой версии сохранены все прежние маршруты, контроллеры, LocalityGeoDirectory, CustomerDestinationResolver и редакторы. Дополнительно работает складской quote и ГАР.

Удаление — отдельный будущий этап после перевода всех потребителей и проверки истории заказов. Регрессионный тест LegacyShippingRemovalTest теперь проверяет СОХРАННОСТЬ контрактов.

Переход тарифов описан в warehouse-service-tariffs.md. Старая схема используется, пока service_tariffs = null; переключение только явное. Фронт в этой доработке не изменяется.
