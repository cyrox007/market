# Координаты склада — локальный пилот

Админка Laravel/Filament: выбор здания запрашивает проверенную иерархию адресного API, затем ищет координаты здания. Центр населённого пункта применяется только для начального положения карты, а не как координаты склада.

Если точного совпадения нет, оператор щёлкает по карте или перемещает метку к въезду. Числа вводить не нужно. Сохранение повторно проверяет источник: `osm` / `building` для совпадения, `operator` / `warehouse_point` для выбранной точки. Существующие координаты сохраняются.

Локальный SQLite `storage/geodata/osm/building-points.sqlite`: 132970 адресных точек, пилотная область 51.4–52.9 N, 38.8–40.0 E. Это НЕ покрытие всей России. Наличие точки OSM не гарантирует адресное совпадение.

Импортёр Node `scripts/geodata/import-building-points.mjs` читает PBF потоком. Аргументы: входной PBF, новый выходной SQLite, bbox `south,west,north,east`. Существующий файл не перезаписывается. Зависимости устанавливаются в `scripts/geodata` через `npm ci`. Повторный импорт выполнять в новый файл, затем менять `ADDRESS_BUILDING_POINTS_PATH`.

Сопоставление консервативное: точное нормализованное название улицы и номер дома, явное совпадение `addr:city`, ограничение окрестностью населённого пункта; разные точки одного адреса считаются неоднозначными. Группы и составные номера без однозначного сопоставления не угадываются. Для полигонов вычисляется представитель здания, не координата въезда. Объекты без `addr:city`, отношения и адреса без улицы пока автоматически не сопоставляются.

Leaflet поставляется локально в `services/backend/resources/vendor/leaflet`; публикация `php artisan filament:assets`. Только подложка карты запрашивается у OpenStreetMap (`ADDRESS_MAP_TILES`); внешнего сервиса геокодирования нет. Источник OSM: © OpenStreetMap contributors, ODbL.

React и прод в рамках пилота не изменяются.

Селекты населённого пункта, улицы и дома заранее показывают до 50 вариантов; дочерние списки ограничены выбранным родителем. Поиск обращается к полному справочнику с тем же родителем. Filament показывает отдельные сообщения загрузки и поиска; при смене родителя под дочерним полем отображается состояние подгрузки. Предзагрузка не загружает всю страну в браузер.
