# Локальный имитатор оплаты Сбера

Ветка `feature/local-sber-simulator`. Только для отдельной локальной базы, не для Beget.
Имитируется состояние банка, а подтверждение оплаты проходит через существующий
`ProcessSberbankCallbackJob` с независимым запросом статуса и проверкой суммы.
HTTP-протокол Сбера, банковская форма, реальные callbacks и фискализация этим не проверяются.

## Запуск на RDP

После установки ветки в рабочую копию в `services/backend/.env`:

```ini
APP_ENV=local
APP_URL=https://svetofor.local
APP_FRONTEND_URL=https://svetofor.local
LOCAL_SBER_SIMULATOR_ENABLED=true
ONEC_API_ENABLED=false
ORDERS_AUTOMATIC_CANCEL_REFUNDS=true
ORDERS_SBERBANK_AUTO_REFUNDS=true
```

Банковские реквизиты не нужны. В терминале Open Server с PHP 8.5 из `services/backend`:

```powershell
php artisan config:clear
php artisan migrate
php artisan sber:simulator-setup
```

Фронт должен обращаться к локальному `/api/v1`. Оформить заказ, выбрать «Тестовая оплата
Сбер», перейти к оплате. На отдельной странице выбрать успех, отказ, отмену или
отсутствие ответа. Обработка уведомления синхронная: worker для имитатора не нужен.
Ссылку имитатора можно открыть снова для повторного уведомления или поздней оплаты.
Заказ отменяется обычной кнопкой магазина; на странице имитатора можно проверить возврат.
Возврат проходит через обычный `AutomaticOrderRefunds`: создание намерения и последующая
сверка статуса, повторное нажатие не создаёт второй возврат. Отключённые флаги возврата
оставляют деньги на рассмотрении, как и в обычной интеграции.

Проверить: успешная оплата, отказ и новая попытка, повторное уведомление, отсутствие
ответа и последующее подтверждение, отмена до/после охлаждения, поздняя оплата отменённого
заказа, однократный возврат. Истечение охлаждения проверять штатным scheduler либо
тестовыми данными, не менять системные часы.

## Ограничения

По умолчанию выключен. Runtime-проверка требует одновременно флаг, local/testing,
APP_URL с localhost/loopback/доменом `.local` и выключенную передачу в 1С; работает
также при закэшированных маршрутах. Формы защищены подписанными временными ссылками
и CSRF. Имитатор не меняет реальную конфигурацию Сбера и не обращается к нему.
Идентификаторы `00000000-*` не отправляются в банк даже после отключения имитатора.
Для возврата к реальному тестовому стенду использовать новую локальную базу/новые
заказы и отключить флаг; банковскую интеграцию затем проверить отдельно.
