# Прототип новой админ-панели

Отдельный React-прототип новой админки проекта «Светофор Мебели».

Прототип всегда строится от актуального `develop`. Текущая база прототипа: `41be4940614f77b4226eaca8c90ec9cbe3fc65fa`.

## Главная цель

Не переносить Filament один в один, а улучшить ежедневную работу оператора каталога.

Основные принципы:

- минимум прокрутки страницы;
- отдельные рабочие области с собственной прокруткой;
- крупные смысловые вкладки;
- длинные формы при необходимости делятся на понятные шаги;
- обязательные поля явно помечены;
- заполненность карточки показывается до сохранения;
- ошибки проверки собраны в одном месте и ведут к конкретному полю;
- редкие поля SEO/1С не мешают ежедневному редактированию;
- категории и комнаты показаны как две разные структуры;
- характеристики сгруппированы по смыслу, а не одной длинной простынёй;
- вариации, остатки, медиа и связи имеют отдельные рабочие экраны.

## Что есть в прототипе

- светлая и тёмная темы;
- стилевое направление на основе админки `cyrox007/vrn-history`;
- рабочее место каталога: дерево разделов → список товаров → редактор;
- переключение «Категории / Комнаты»;
- редактор товара по реальной структуре актуального `develop`;
- индикатор заполненности;
- сводка ошибок и рекомендаций;
- пошаговый раздел «Основное»;
- крупные вкладки:
  - Основное;
  - Характеристики;
  - Вариации;
  - Остатки;
  - Медиа;
  - Связи;
  - SEO / 1С.

Данные пока демонстрационные. Backend не меняется.

## Запуск

Из корня репозитория:

```bash
npm install
npm run dev --workspace=svetofor-admin-prototype
```

После запуска:

```text
http://localhost:5174
```
