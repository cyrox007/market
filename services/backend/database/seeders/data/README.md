# Инструкция по заполнению регионов доставки

## Формат CSV файла

Создайте файл `shipping_locations.csv` в этой директории со следующим форматом:

```csv
Федеральный субъект,Район/Город,Населенный пункт,Стоимость доставки
Краснодарский край,Азовский район,г. Азов,150
Краснодарский край,Азовский район,с. Астраханка,150
Краснодарский край,,г. Краснодар,150
```

### Столбцы:

1. **Федеральный субъект** (обязательно) - область, край, республика
2. **Район/Город** (необязательно) - район или город в составе региона. Если пусто, населенный пункт будет привязан напрямую к федеральному субъекту
3. **Населенный пункт** (обязательно) - город, село, поселок и т.д. Может содержать префиксы: г., с., ст., пос., пгт
4. **Стоимость доставки** (обязательно) - числовое значение

### Примеры форматов населенных пунктов:

- `г. Москва` - город
- `с. Астраханка` - село
- `ст. Брюховецкая` - станица
- `пос. Верхнерусский` - поселок
- `пгт Джубга` - поселок городского типа

## Запуск сидера

```bash
php artisan db:seed --class=NewShippingLocationsSeeder
```

## Важно

- Сидер **полностью очищает** все существующие локации перед заполнением
- Убедитесь, что у вас есть резервная копия данных перед запуском
- Если CSV файл не найден, будут использованы встроенные примеры данных
