# Интеграции склада и заказов

В этой папке находятся реализации обмена данными с внешними системами по **заказам и остаткам** (не каталог).

## Светофор 1C (заказы и остатки)

- **Класс:** `Integration1CApiService`
- **Назначение:** отправка заказов в 1С, отмена/завершение заказов, получение остатков товаров.
- **Конфиг:** `config/services.php` → секция `onec`. Переменные окружения: `ONEC_API_BASE_URL`, `ONEC_API_KEY`, `ONEC_API_TIMEOUT`, `ONEC_API_ENABLED`.

Импорт каталога (категории и товары) из API Светофор реализован отдельно: см. `App\Services\Catalog\Integrations` и страницу «Синхронизация каталога» в админке (группа «Интеграции»).
