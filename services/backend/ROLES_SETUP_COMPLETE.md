## Как назначить роль суперадмина пользователю:

### Вариант 1: Существующему пользователю
```bash
docker exec sv_app php assign_super_admin.php ваш_email@example.com
```

### Вариант 2: Создать нового суперадмина
```bash
docker exec sv_app php assign_super_admin.php admin@example.com "Admin Name" password123
```

### Вариант 3: Через админку Filament
1. Войдите в админку: `http://localhost:8000/admin_sv`
2. Перейдите в раздел **"Пользователи"**
3. Откройте пользователя для редактирования
4. В разделе **"Роли и разрешения"** выберите роль **"super_admin"**
5. Сохраните

## Что доступно в админке:

### Новый раздел "Права доступа":
- **Роли** (`/admin_sv/roles`) - управление ролями и назначение разрешений
- **Разрешения** (`/admin_sv/permissions`) - просмотр всех разрешений

### В разделе "Пользователи":
- Добавлена секция **"Роли и разрешения"** для назначения ролей
- В таблице пользователей отображаются назначенные роли

## Структура разрешений:

Каждый ресурс имеет 5 стандартных разрешений:
- `viewAny {resource}` - просмотр списка
- `view {resource}` - просмотр записи
- `create {resource}` - создание
- `update {resource}` - редактирование
- `delete {resource}` - удаление

Примеры:
- `viewAny products`
- `create orders`
- `update users`
- `delete categories`

## Проверка работы:

1. Войдите в админку под пользователем с ролью `super_admin`
2. Убедитесь, что видите раздел **"Права доступа"** в меню
3. Перейдите в **"Роли"** - должны быть видны все 5 ролей
4. Перейдите в **"Разрешения"** - должны быть видны все 90 разрешений
5. Откройте любого пользователя - должна быть секция для назначения ролей

## Важно:

- Если пользователь не имеет прав на ресурс, он не увидит его в меню
- Все действия автоматически проверяются через Policy классы
- Роли можно назначать как через админку, так и программно
